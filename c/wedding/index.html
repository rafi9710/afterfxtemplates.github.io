How these templates work

Each template is an editable After Effects project file. Replace the names, dates and venue, then render horizontal for the function screen and vertical for WhatsApp. Fonts, PNG footage, audio and layered PSD files are all included in the download.

If you do not use After Effects, we can personalise the template for you and deliver a finished video — message us on WhatsApp with the template you like.
